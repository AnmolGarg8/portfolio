## 🛠️ Featured Engineering Projects

### 01. NoteNetra — IoT Fintech Platform
*A bridge to credit for the underserved.*
*   **The Problem:** MSMEs and farmers often operate in cash-heavy environments with zero digital footprint, making them "invisible" to traditional lenders.
*   **The Solution:** An ESP32-powered system that captures offline cash transactions and syncs them to a live cloud dashboard via custom telemetry pipelines.
*   **Tech Stack:** ESP32, C++, Firebase, Real-time Data Visualization.
*   **Impact:** Converts raw, unstructured cashflow into verifiable credit insights, enabling financial inclusion.

### 02. AlKosh · SAMARTH-AI — NLP Taxonomy Engine
*Intelligence-driven enterprise onboarding.*
*   **The Challenge:** Automating the classification of complex, unstructured product descriptions into structured enterprise taxonomies.
*   **The Solution:** Developed a semantic similarity engine using NLP models to classify product data with high-confidence scoring.
*   **Tech Stack:** Python, NLP (Transformers/BERT), REST APIs, FastAPI.
*   **Impact:** Drastically reduced manual onboarding time for MSMEs while maintaining enterprise-grade data integrity.

### 03. Smart Vape Detection — Hardware Alert Engine
*Real-time environmental monitoring.*
*   **Core:** A hardware-software integration using MQ sensors and Embedded C to detect and alert authorities of restricted substance usage in real-time.
